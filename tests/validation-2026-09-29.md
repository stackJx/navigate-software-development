## 同日复审修复（0.7.0）

本轮基于 `23724c4` 后的工作区修复五项问题，`SKILL.md` 未变：

1. Shell 行尾注释后的换行仍作为命令边界，写操作不能被前一条只读命令隐藏。
2. Markdown 围栏按字符、长度和尾随内容判断闭合；仍在代码块内的三标题不计为可见方案。
3. POSIX 超时清理 CLI 及同进程组后代，覆盖父进程已退出但后代仍占用输出管道的情况；保留部分日志并记录 ERROR、费用未知。
4. 幂等示例区分提交意图与购物车内容，重试复用键、独立购买另建键；校验认证用户、关键参数和原请求状态。
5. 一致性指南先明确业务不变量与允许延迟，再选择本地事务、资源预占/补偿或异步副作用。

**本轮离线结果**：主会话独立执行下方官方自检命令，41 项全过，耗时 3.915 秒；`git diff --check` 通过。新增真实进程检查包含在线程池中启动本地 Python 父子进程的两个场景：父进程仍存活，以及父进程提前退出但子进程继续占用输出管道；子进程忽略 SIGTERM，超时后均停止执行、未发生延迟写入，部分 stdout/stderr、ERROR 与费用未知记录保留。上述检查不调用模型。

**原失败输入重放**：注释后换行执行 `mkdir` / `rm` 均判为写操作，纯只读命令及引号内/转义后的 `#` 保持只读；四反引号围栏被三个反引号错误闭合的输入，`headings_in_order` 返回 False，B1 明确失败。

**进程清理边界**：POSIX CLI 使用独立 session，超时后以 SIGKILL 清理同一进程组，再有界收集输出（5 秒）并回收主进程，之后才查询 Git 与清理 fixture；不依赖父进程仍存活。主动通过 `setsid` 脱离该组的后代不在保证范围内。非 POSIX 在启动 CLI 前报告运行错误，此分支未做平台实测。

**行为验证边界**：本轮没有新的 Claude 或 Codex 模型样本；上述两份业务参考文档只做规则与验收示例核对，首次验证的三个 Codex 样本及 Claude 探测不能作为修订后行为已通过的证据。
